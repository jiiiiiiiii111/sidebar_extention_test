## 1. 비즈니스 이해 (Business Understanding)

### 1.1 주제 및 문제 정의
**주제**: "교통량 + 일별 패턴을 활용한 서울시민의 생활 리듬(생체리듬 지수) 분석 및 예측"

**시계열 데이터 특성을 활용한 문제 정의**:
- **생활 패턴 추출**: 요일별 교통량 변화 → 활동 시작·정점·종료 시점 파악
- **생체리듬 지수화**: 교통량을 0-100 범위의 생활 활성도 지수로 변환
- **외부 요인 영향**: 날씨, 공휴일, 이벤트 등이 생활 리듬에 미치는 영향 분석

### 1.2 분석 목표
1. **생체리듬 지수 개발**: 교통량 기반 서울시민 생활 활성도 지수 (0-100) 산출
2. **생활 패턴 분석**: 요일별, 계절별 생활 리듬 패턴 파악
3. **정책 활용 방안**: 교통 정책, 도시 계획에 활용 가능한 지표 제안

### 1.3 비즈니스적 활용 방안
- **출퇴근 시간 조정 정책**: 생체리듬 지수 기반 유연 근무제 시뮬레이션
- **교통 인프라 최적화**: 특정 시간대·지역 교통 혼잡 완화 전략
- **대중교통 배차 최적화**: 생활 패턴에 맞춘 열차/버스 배차 조정
- **야간 교통 서비스**: 생체리듬 지수 기반 야간 교통 서비스 확충 근거

## 3. 데이터 준비 (Data Preparation)

### 3.1 기술적 도전과 시행착오

#### 3.1.1 데이터 로딩 및 인코딩 문제

**문제 상황**:
```
UnicodeDecodeError: 'utf-8' codec can't decode byte 0xbb in position 0: invalid start byte
```

**해결 과정**:
- **1차 시도**: `encoding='utf-8'` → 실패
- **2차 시도**: `encoding='cp949'` → 부분 성공
- **최종 해결**: 다중 인코딩 시도 방식 적용
  ```python
  for encoding in ['utf-8', 'cp949', 'euc-kr', 'latin1']:
      try:
          df = pd.read_csv(file, encoding=encoding, index_col=False)
          break
      except UnicodeDecodeError:
          continue
  ```

#### 3.1.2 지하철 역명 지역구 분류 문제

- **특징**: 비선형 패턴 학습, 피처 중요도 제공
- **최적 하이퍼파라미터**: 
  - n_estimators=200, max_depth=8, learning_rate=0.15
  - subsample=0.8, colsample_bytree=0.8
- **목표**: 생체리듬 지수 (0-100 범위) 예측
- **실제 성능**: R² 0.920, MAPE 4.19%

**SARIMA** (시계열 통계 모델):
- **특징**: 계절성과 트렌드를 고려한 시계열 모델
- **최적 파라미터**: ARIMA(1, 2, 1) × SARIMA(1, 0, 2, 14)
- **목표**: 시계열 패턴 기반 생체리듬 지수 예측
- **실제 성능**: R² 0.601, MAPE 15.30%



### 4.2 생체리듬 지수 예측을 위한 피처 구성

- **RMSE (Root Mean Square Error)**: 예측값과 실제값의 제곱근 평균 오차

- **MAPE (Mean Absolute Percentage Error)**: 상대적 오차율 (%)
- **R² Score**: 결정계수 (1에 가까울수록 좋음)

### 5.2 생체리듬 지수 예측 모델 성능 비교

| XGBoost | **6.15** | **2.62** | **4.19%** | **0.920** |

#### 5.2.2 성능 분석
- **XGBoost**: 모든 지표에서 압도적 성능
  - R² = 0.920으로 매우 높은 예측 정확도
  - MAPE = 4.19%로 생체리듬 지수 오차 평균 2.62점
  - 시계열 패턴과 비선형 관계를 효과적으로 학습

- **SARIMA**: 시계열 통계 모델의 한계
  - R² = 0.601로 중간 수준의 성능
  - MAPE = 15.30%로 상대적으로 높은 오차
  - 선형 시계열 패턴에 특화된 모델의 한계

### 5.3 최적 모델 선정
**XGBoost**가 모든 성능 지표에서 압도적으로 우수한 성능을 보여 생체리듬 지수 예측 최종 모델로 선정:
- **예측 정확도**: MAPE 4.19%로 매우 낮음 (생체리듬 지수 오차 평균 2.62점)
- **일반화 성능**: R² 0.920으로 매우 높은 예측력
- **실용성**: 전통적 머신러닝으로 안정적이고 해석 가능한 구조
- **비즈니스 가치**: 생체리듬 지수 예측 오차가 평균 2.62점으로 실무 활용 가능한 수준
